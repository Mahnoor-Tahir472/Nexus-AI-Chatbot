Nexus AI Chatbot

Nexus AI Chatbot is a modern AI-powered web application developed using Django and the Gemini API.  
The project is designed to provide intelligent conversational responses through a clean and interactive user interface.

Overview

This chatbot application integrates advanced AI capabilities with a responsive web-based frontend, allowing users to interact with an AI assistant in real time. The project demonstrates backend development, API integration, and deployment skills.

Features

- Real-time AI-generated responses
- Gemini API integration
- Responsive and modern user interface
- Django-based backend architecture
- Smooth chatbot interaction experience
- Live deployment on PythonAnywhere

Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- Gemini API
